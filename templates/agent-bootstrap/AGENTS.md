# Agent bootstrap

Before substantive work in this repository:

1. Read the local harness adoption manifest at `<HARNESS_ADOPTION_MANIFEST>`.
2. Load the exact immutable harness ref declared by that manifest, beginning with `HARNESS.md`.
3. Load only the companion specifications relevant to the task; do not replace the pinned
   contract with memory or a moving `main` branch.
4. Preserve the authority, evidence, gate, pedagogy and handoff boundaries declared by the
   harness and local manifest.
5. When learning-oriented work introduces or meaningfully re-encounters non-trivial
   mathematical notation, apply `pedagogy/MATHEMATICAL_NOTATION_CAPITALIZATION.md` from the
   pinned harness and update the consumer notation registry when warranted.

If the pinned dependency cannot be loaded, report the missing dependency before claiming
harness compliance. Bounded orientation work is allowed; outcome-bearing work and scientific
gate release are not.

Keep this file short. It is the automatically discovered map into the versioned system of
record, not a duplicate of the harness.
